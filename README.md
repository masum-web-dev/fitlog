# 🏋️‍♂️ FitLog - Modern Workout & Fitness Application

FitLog is a modern, responsive web application built with Next.js and React, designed to help fitness enthusiasts browse workouts, build daily fitness plans, track calories, and manage their routines seamlessly.

---

## 🚀 Technologies Used

* **Framework:** Next.js (App Router)
* **Library:** React.js
* **Styling:** Tailwind CSS
* **State Management:** React Context API & LocalStorage
* **Notifications:** React Toastify

---

## ✨ Key Features

1. **Comprehensive Workout Library:** Browse a wide range of professional exercises with detailed descriptions, equipment requirements, muscle groups, and training instructions.
2. **Interactive Daily Planning:** Add workouts to "Today's Plan" or "Saved" list with live updates and dynamic count badges in the navigation bar.
3. **Smart Sorting & Filtering:** Easily sort your workouts based on duration, calories burned, and user ratings to optimize your routine.
4. **Persistent State Management:** Built-in `LocalStorage` support ensuring your workout plans and saved items remain intact even after browser reloads.
5. **Interactive Progress Tracking:** Mark workouts as "Done" on-the-fly with real-time toast notifications and interactive UI states.
